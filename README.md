# 文件树生成

> 自动扫描指定文件夹，生成清晰的文件树结构，并复制到系统剪贴板

## 1. 简介

- 一键生成文件夹的完整树形结构
- 自动复制到剪贴板，即粘即用
- 完美展示项目目录、归档结构

## 2. 示例

选中文件夹后一键触发，自动生成树形结构并复制到剪贴板：

```
文件夹: D:/Projects/MyApp
├── src
│   ├── main.py
│   ├── utils
│   │   ├── helper.py
│   │   └── config.py
│   └── tests
│       └── test_main.py
├── README.md
└── requirements.txt
```

## 3. 快速开始

- **自动安装（推荐）**
  - 下载 [不忙脚本盒子](https://www.bm-box.cn) 后，打开 → 脚本市场 → 搜索「文件树生成」→ 点击安装。
  - 盒子会自动配置环境，安装后通过快捷键或右键菜单即可使用。

- **手动安装**
  - 需自行安装 PowerShell 5.1+，在脚本目录执行入口命令。

## 4. 启动方式（通过盒子部署）

- **全局快捷键启动** — 在盒子内为脚本自定义快捷键，选中文件夹后按下直接生成。
- **右键菜单启动** — 文件夹上右键 → 「不忙脚本盒子」→「文件树生成」，一键完成。

## 5. 全部功能一览

| 功能 | 说明 |
|------|------|
| 目录树生成 | 递归扫描文件夹，生成树形结构 |
| 复制到剪贴板 | 结果自动写入系统剪贴板 |
| 完成通知 | 处理完成后在盒子界面显示通知 |
